5. Componentes reutilizáveis identificados

Padrão consistente entre as 17 telas — implementar como componentes compartilhados no código:

  • Card base: fundo branco, borda 1px #E4DCC8, radius 6px, padding 20–28px.
  • Barra de progresso/score: trilho #EFE7D6 8–10px, preenchimento na cor do pilar ou dourado.
  • Badge de status: fundo tonal + texto escuro correspondente, mono 11px, radius 3–4px.
  • Badge de pilar: pill sólida na cor do pilar, texto branco, mono 10–11px.
  • Tabela: header mono uppercase 11px sobre #F7F3EA, linhas com borda inferior #F0EAD9.
  • Kanban card: borda esquerda de 4px na cor do pilar de origem.

6. Dados de exemplo (mock) usados no protótipo

Todas as telas usam dados fictícios de uma empresa exemplo ("Empresa Atlas Ltda.") para ilustrar estados preenchidos — nenhum dado real de cliente. Substituir por integração com o backend do sistema.

7. Próximos passos sugeridos

  • Validar states vazios/erro para cada tela (ainda não desenhados).
  • Especificar breakpoints responsivos (protótipo atual é desktop-first).
  • Detalhar microinterações (hover, drag-and-drop no Kanban, edição inline no Canvas/BMC).
