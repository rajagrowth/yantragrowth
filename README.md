# Yantra Growth OS — Design

Identidade visual e protótipo de UI do Yantra Growth OS (Raja Growth).

## Arquivos
- `Yantra Growth OS - Manual de Marca.dc.html` — manual de marca completo (conceito, logo, cores, tipografia, aplicações).
- `Yantra Growth OS - Telas.dc.html` — protótipo navegável com as 17 telas do produto (Fundação, Diagnóstico, Estratégia, Growth, Inteligência, Certificação).
- `Yantra Growth OS - Analise do Sistema.dc.html` — documento de análise do sistema (arquitetura de telas, paleta, tipografia, componentes, próximos passos).
- `support.js`, `doc-page.js` — runtime dos Design Components (não editar).

## Como abrir
Cada `.dc.html` é autocontido — abra direto no navegador ou importe via `<dc-import>`.
